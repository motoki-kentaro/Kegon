# Security Policy

## Supported versions

Kegon is experimental and has no releases yet. Security fixes are made only on the `main` branch.

## Reporting a vulnerability

Please do **not** report security vulnerabilities in public issues, pull requests, or discussions.

Report them privately through GitHub's [private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability) (the **Report a vulnerability** button in the repository's security section).

If that option is not available yet, open a public issue that only asks for a private contact channel, and leave out any vulnerability details.

Please include, where possible:

- the affected commit or version,
- the platform and shell used,
- steps to reproduce, and
- the impact you expect.
